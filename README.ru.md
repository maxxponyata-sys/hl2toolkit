# HL2 Toolkit

[English](README.md) · **Русский** · [Deutsch](README.de.md)

Простой редактор карт для **Half-Life 2** для новичков, в духе редакторов Far Cry. Перетаскиваете модели в 3D-мир, лепите рельеф кистями, жмёте **F5** — и играете на своей карте.

Написан на **C#** (WinForms + OpenGL напрямую). Сторонних библиотек нет, вся программа — один файл для Windows x64.

---

## Возможности

- **Drag and drop.** В библиотеке около 1400 моделей Half-Life 2 с миниатюрами в настоящих текстурах, а также NPC, оружие, предметы, транспорт, свет и блоки для стен. Перетащите что угодно в мир или поставьте двойным кликом перед камерой.
- **Свои модели.** Бросьте `.obj` в окно. Мастер импорта сам пересчитает размеры, сделает текстуру (VTF/VMT) и исходники модели (SMD/QC) и скомпилирует её через `studiomdl`. Модель появится во вкладке **«Мои модели»**.
- **Управление как в Far Cry.** Зажмите ПКМ и летайте на WASD. Объекты тащатся мышью по земле или за стрелки гизмо — перемещение, вращение, масштаб. Есть привязка к сетке и отмена/повтор.
- **Кисти рельефа.** Поднять, опустить, сгладить, выровнять и раскрасить второй текстурой. Рельеф сохраняется как дисплейсменты Source.
- **Мир.** Время суток, сторона солнца, небо, туман и вода.
- **Сборка в один клик.** VMF → VBSP → VVIS → VRAD → `hl2/maps`, затем запуск игры. Карта сама закрывается небом, поэтому утечек (leak) не бывает.
- **Режим RTX.** Если установлен Half-Life 2 RTX (или RTX Remix в папке HL2), карта копируется туда и запускается с трассировкой лучей. Шейдеры RTX Remix компилирует сам при первом запуске.
- **Экспорт VMF.** Карту можно доработать в Hammer.
- **Умный выбор типа модели.** Модели, которые Half-Life 2 разрешает только как физические (бочки, ящики и т. п.), определяются автоматически.

## Требования

- Windows 10/11 x64
- **Half-Life 2** в Steam. Инструменты компиляции (`vbsp`, `vvis`, `vrad`, `studiomdl`) идут вместе с игрой.
- Для режима RTX (по желанию): Half-Life 2 RTX и видеокарта с поддержкой RTX

## Скачать

Возьмите `HL2Toolkit.exe` в разделе [**Releases**](../../releases) и запустите. Устанавливать ничего не нужно, .NET тоже. Папка игры находится через Steam; если не нашлась — укажите её в **Настройки → Папка Half-Life 2**.

## Управление

| Действие | Клавиши |
|---|---|
| Осмотреться / лететь | Зажать **ПКМ** + мышь, **W A S D**, **Q / E** вниз/вверх, **Shift** — быстрее |
| Выбрать / тащить по земле | **ЛКМ** |
| Двигать / вращать / масштаб | **W / E / R** |
| Камеру к объекту / к центру карты | **F** / **Home** |
| Поставить на землю | **End** |
| Копия / удалить | **Ctrl+D** / **Del** |
| Отменить / повторить | **Ctrl+Z** / **Ctrl+Y** |
| Собрать и играть / только собрать | **F5** / **F7** |
| Кисть рельефа, обратное действие | **ЛКМ**, с **Ctrl** — наоборот |

## Сборка из исходников

Нужен .NET SDK (проект собирается под `net11.0-windows`).

```bat
cd src\HL2Toolkit
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o ..\..\dist
```

Проверка ядра без интерфейса: `HL2Toolkit.exe --selftest`. Программа прочитает модели, соберёт и скомпилирует тестовую карту и запишет результат в `selftest.log`.

## Структура проекта

```
src/HL2Toolkit/
  Source/   чтение и запись VPK, MDL/VVD/VTX, VTF, VMT
  Build/    генератор VMF, цепочка компиляции, импорт OBJ, studiomdl
  Render/   OpenGL-вьюпорт, камера, гизмо, кисти рельефа, кэш ассетов
  UI/       главное окно, библиотека, свойства, мастер импорта, тёмная тема
```

## Важно

Это фанатский инструмент, он не связан с Valve и NVIDIA. Нужна своя копия Half-Life 2. Файлы игры в проект не входят.
